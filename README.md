## 💻 Tecnologias e Ferramentas

As principais tecnologias, bibliotecas e ferramentas de estudo que formam a base deste projeto e da minha atual jornada de aprendizado:

- **Frontend Core:** HTML5, CSS3, JavaScript (ES6+)
- **Ecossistema React:** React, Next.js
- **Estilização & Animações:** Tailwind CSS, Framer Motion
- **Outros:** Phosphor Icons (Ícones)

---

## ✨ Funcionalidades em Destaque

- **Filtro Dinâmico de Projetos:** Sistema inteligente de categorização que renderiza e filtra projetos automaticamente a partir de um Array de dados, facilitando muito a adição de novos trabalhos.
- **Design Moderno e Responsivo:** Totalmente adaptado para dispositivos móveis, tablets e desktops (Mobile First).
- **Animações Fluidas:** Transições de tela e interações de componentes suaves utilizando o Framer Motion para uma melhor Experiência do Usuário (UX).

## 🚀 Como rodar o projeto localmente

Siga os passos abaixo para rodar a versão atualizada (Next.js) do portfólio na sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/WelberthM/MeuPrimeiroPortifolio.git
   ```

2. **Acesse a pasta do projeto em React/Next.js:**
   ```bash
   cd MeuPrimeiroPortifolio/portfolio-next
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```
   *(ou `yarn install` se estiver usando Yarn)*

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. **Acesse no seu navegador:**
   Abra `http://localhost:3000` para ver a aplicação rodando localmente.
